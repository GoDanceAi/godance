# Godance — Marketing site

SEO/GEO-optimized static site for `godance.ai`. Astro 5 + Tailwind CSS, deployed to
Cloudflare Pages.

## Stack rationale

- **Astro** — SSG-first; every page renders as static HTML at build time. Crawlers
  (Google, Bing, DDG) and AI agents (Perplexity, ChatGPT browsing, Claude.ai web) get
  fully-rendered HTML without executing JavaScript. SPAs (Vite+React) fail this.
- **Tailwind** — utility-first, zero CSS shipped that isn't used (the JIT compiler purges
  per page).
- **Cloudflare Pages** — global edge POPs, integrates with the existing CF DNS used for
  Godance's failover, generous free tier.

## Local dev

```bash
npm install
npm run dev          # http://localhost:4321
```

## Build

```bash
npm run build        # → ./dist/
npm run preview      # serve ./dist locally
npm run lint         # astro check: typecheck .astro and .ts files
```

## Deploy to Cloudflare Pages

```bash
# Via wrangler (recommended):
npx wrangler pages deploy dist --project-name=godance-marketing

# Or via the Cloudflare dashboard:
#   Build command:    npm run build
#   Output directory: dist
#   Node version:     20+
```

Set `SITE_URL` at build time for non-prod (e.g. `SITE_URL=https://preview.godance.ai npm run build`).
Defaults to `https://godance.ai`.

## Project layout

```
frontend-marketing/
├── astro.config.mjs        # Astro + Tailwind + sitemap integrations
├── tailwind.config.mjs     # Brand colors, fonts
├── tsconfig.json           # Strict TS (astro/tsconfigs/strict)
├── public/
│   ├── favicon.svg
│   ├── llms.txt            # GEO content for AI agents
│   ├── robots.txt          # Allow-all + sitemap reference
│   ├── _headers            # CF Pages security + cache headers
│   └── _redirects          # CF Pages redirects (e.g. /discord)
└── src/
    ├── layouts/
    │   └── Layout.astro    # <head>: title, meta, canonical, OG, JSON-LD
    ├── components/
    │   ├── Nav.astro
    │   └── Footer.astro
    └── pages/
        ├── index.astro     # Landing — Org / SoftwareApplication / FAQ JSON-LD
        ├── pricing.astro   # Pricing table — Breadcrumb JSON-LD
        ├── models.astro    # Model catalog — ItemList JSON-LD (good for AI agents)
        ├── docs/index.astro # Documentation hub
        └── status.astro    # Provider status (data feed lands Session 11)
```

## SEO / GEO

- **Per-page JSON-LD** (`Layout.astro` `jsonLd` prop) — Google rich results + AI agents.
- **llms.txt** at root — concise machine-readable summary for AI assistants.
- **Sitemap** — auto-generated by `@astrojs/sitemap` from page routes.
- **Canonical URL** on every page via `<link rel="canonical">`.
- **Open Graph + Twitter Card** — social previews on link shares.
- **No client-side hydration** by default — everything pre-rendered, no JS needed to read content.
