Use [codex-session-prompt.md](codex-session-prompt.md) to run all five streams from one coordinating Codex session. These openings also apply to a delegated worker. Read the owned brief fully; this file is not a substitute.

A coordinator may delegate implementation, but keeps shared-file assignments and publication/check monitoring consistent.
